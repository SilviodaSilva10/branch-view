# Branch

Existem dois tipos de branch manster e as sub-mansters

As outras versões das futures não devem ser commitadas na branch manster
se não estiverem terminadas, só podem ser colocadas na branch manster quando estiverem terminas.

**As branch servem para:**

Permitirem aos desenvolvidores, desenvolverem os seus projectos consoante as suas ferramentas e juntar a sua versão  (**BRANCH MANSTER**) final quando cada parte terminar de desenvolver.

Permitem criar versões seguras para backup.
